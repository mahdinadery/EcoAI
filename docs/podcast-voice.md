# صدای پادکست با همان سرویس هوش مصنوعی

این سند مشخص می‌کند «خواندن بلندِ خلاصه» چطور از **همان سرویسی** استفاده می‌کند که تحلیل با آن
کار می‌کند، و کجاها سرویس فعلی توانایی آن را ندارد. هیچ سرویس دوم و هیچ کلید جدیدی لازم نیست؛
اگر کلید فعلی مسیر صوتی داشته باشد، پادکست از همان تغذیه می‌شود.

## مسیرها بر اساس کلید موجود

منبع تصمیم، همان چیزی است که `src/lib/ai/completion.ts` برای تحلیل می‌خواند
(`AI_API_KEY` و معادل‌های `OPENAI_API_KEY` / `GEMINI_API_KEY` / `VERTEX_API_KEY` /
`GROQ_API_KEY` / `OPENROUTER_API_KEY`، به‌همراه `AI_API_BASE_URL` و نام‌های جایگزین آن
`AI_BASE_URL` / `OPENAI_BASE_URL` / `OPENAI_API_BASE` — هم‌راستا با `resolveEffectiveBaseUrl`):

| کلید / سرویس | مسیر صوتی | نتیجه |
| --- | --- | --- |
| `sk-…` (OpenAI یا هر درگاه اوپن‌ای‌کمپتبل که `/audio/speech` را سرو می‌کند) | `POST {base}/audio/speech` | فایل MP3؛ مدل `gpt-4o-mini-tts` و در نبود آن `tts-1` |
| `AIza…` (Google AI Studio) یا `AQ.…` (Vertex Express) | `POST {model}:generateContent` با `responseModalities: ["AUDIO"]` | PCM ۲۴kHz که با هدر ۴۴ بایتی WAV بسته‌بندی می‌شود؛ مدل `gemini-2.5-flash-preview-tts` |
| `gsk_…` (Groq)، `sk-or-…` (OpenRouter)، `xai-…`، و هر درگاهی که فقط chat را پروکسی می‌کند | — | `route: "none"` و دلیل صریح؛ هیچ درخواستی ساخته نمی‌شود |

قاعدهٔ مهم: مسیر صوتی «حدس» زده نمی‌شود. درگاه اوپن‌ای‌کمپتبل تست می‌شود و اگر `/audio/speech`
را نداشته باشد همان ۴۰۴ یا پاسخ JSON به‌عنوان دلیل نمایش داده می‌شود — نه یک پیام کلی.

## تست از داشبورد

`/admin/ai-config` → بخش **«صدای پادکست (با همان سرویس هوش مصنوعی)»**:

- باز کردن صفحه فقط `GET /api/ai/tts` را صدا می‌زند — یک بررسی محلی و رایگان (بدون فراخوان
  سرویس و بدون توکن) که مسیر، میزبان، مدل، صدا و سقف نویسه را نشان می‌دهد.
- دکمهٔ «تست و پخش نمونه» تنها چیزی است که به سرویس درخواست می‌فرستد. فایل صوتی در یک
  `blob:` URL داخل همان مرورگر پخش و قابل دانلود است؛ **چیزی در دیتابیس ذخیره یا به کانال
  ارسال نمی‌شود**.
- اگر سرویس مسیر صوتی نداشته باشد، به‌جای فرم تست، پیام «برای فعال‌سازی کلید OpenAI یا Google
  را در `AI_API_KEY` / `AI_API_BASE_URL` بگذارید» دیده می‌شود — همان متغیرهایی که تحلیل از آن‌ها
  استفاده می‌کند.

از خط فرمان هم همان دو کار شدنی است (پاسخ‌ها از `ADMIN_ACCESS_KEY` محافظت می‌شوند؛ در حالت
کوکی فقط با نشست مدیریتی معتبر کار می‌کنند):

```bash
curl -sS "https://<app-url>/api/ai/tts?key=<ADMIN_ACCESS_KEY>"          # فقط بررسی توانایی
curl -sS -X POST -o sample.mp3 "https://<app-url>/api/ai/tts?key=<ADMIN_ACCESS_KEY>&format=audio" \
  -H 'content-type: application/json' -d '{"text":"نمونهٔ کوتاه"}'      # ساخت یک فایل صوتی
```

## متغیرهای محیطی

همه اختیاری‌اند و فقط overrides‌اند؛ تنظیم‌کردن هیچ‌کدام برای کار کردن لازم نیست:

| متغیر | پیش‌فرض | نقش |
| --- | --- | --- |
| `AI_TTS_MODEL` | `gpt-4o-mini-tts` برای مسیر اوپن‌ای‌کمپتبل، `gemini-2.5-flash-preview-tts` برای Google | نام مدلی که به سرویس فرستاده می‌شود |
| `AI_TTS_VOICE` | `alloy` / `Kore` | صدا؛ اگر سرویس آن را نپذیرد همان خطا نمایش داده می‌شود و به حالت سکوت نمی‌رود |
| `AI_TTS_MAX_CHARS` | `1200` (بازهٔ مجاز ۲۰۰ تا ۴۰۰۰) | سقف نویسه هر درخواست؛ برش روی پایان جمله انجام می‌شود، نه وسط کلمه |

`AI_PROXY_URL` / `HTTPS_PROXY` هم همان‌جا که برای تحلیل اعمال می‌شوند اینجا هم اعمال
می‌شوند (از `getAiDispatcher` مشترک استفاده می‌شود و درخواست با `undiciFetch` فرستاده
می‌شود، چون fetch سراسری Node گزینهٔ `dispatcher` را نادیده می‌گیرد).

## محدودیت‌های آگاهانه

- این لایه فقط صدا می‌سازد. **ذخیرهٔ دائمی فایل، `sendAudio` در ربات‌ها، زمان‌بندی هفتگیِ
  صوتی و زیرنویس هنوز ساخته نشده‌اند**؛ روی Render دیسک ناپایدار است، پس برای پخش خودکار
  باید فایل جایی بیرون از دیسک بماند.
- هیچ نوشتن دیتابیس، هیچ retry و هیچ وضعیت ارسالی این‌جا وجود ندارد: خطای صوتی نباید شبیه
  خطای ارسال دیده شود.
- مهلت هر درخواست ۴۵ ثانیه و سقف کارکرد ۶۰ ثانیه است؛ متن بلندتر از `AI_TTS_MAX_CHARS` بریده
  می‌شود (پارامتر `truncated: true` در پاسخ) و بخش‌بندیِ طولانی‌تر کار لایهٔ بعد است.
- متن درخواست قبل از ارسال به سرویس، کلید API و عبارت `?key=…` از هر پیامی که سرویس برمی‌گرداند
  حذف می‌شود (`redactTtsSecret`)؛ لاگ و UI هیچ‌گاه کلید نشان نمی‌دهند.
- آمار دقیق تلفظ فارسی و کیفیت صدا فقط با یک نمونهٔ واقعی روی همان کلیدِ مستقرشدنی سنجیده
  می‌شود؛ در این سند ادعایی دربارهٔ «طبیعی بودن» صدا نیست.
